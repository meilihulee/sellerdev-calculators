Frequently asked questions

How is LLM API cost calculated?

+

Monthly cost = requests × (uncached input tokens × input price + cached input tokens × cached price + output tokens × output price) ÷ 1,000,000. Batch requests are typically billed at 50% of the standard rate.

Why are output tokens more expensive than input tokens?

+

Generating tokens is sequential and compute-heavy, so providers price output at roughly 4–5× input on most models. Shortening responses is often the fastest way to cut a bill.

How much does prompt caching save?

+

Cached input is commonly billed at around 10% of the normal input price (sometimes less), so a long, repeated system prompt with a high cache hit rate can cut input spend by up to 90%. Cache writes may cost extra.

Are open-weight models really cheaper?

+

Hosted open-weight models (Llama, Qwen, DeepSeek, gpt-oss) are often 10–100× cheaper per token than flagship closed models. Whether they are good enough depends on your task, so test quality before switching.

Do these prices change?

+

Often. Several current rates are introductory and scheduled to rise (for example Gemini 3.8 Flash on January 1, 2027). Check each provider's pricing page and edit the prices in the calculator before making decisions.
